Kapuas River Run — a bush plane flying the Kapuas River from Putussibau to the sea. The river is the route: thread the rings, drop mail and medicine to named villages, and beat the monsoon wall home. Three legs, shared cargo batching, turnaround refits that cost wall time, and a flight-recorder debrief.

## Run it

```sh
node serve.ts
```
